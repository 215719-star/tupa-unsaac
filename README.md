## Contenido

- `index.html`, `estilos.css`, `datos.js`, `app.js`, `logo.png`: interfaces de la plataforma. Se abre `index.html` en el navegador.
- `base-de-datos/`: script SQL de PostgreSQL (`tupa_unsaac.sql`).

## Metodología

Scrum, con sprints de dos semanas. Ramas por tarea (`feature/...`) y pull requests hacia `main`.
